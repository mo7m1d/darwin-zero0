# Authorized Bug Bounty Policy

DARWIN may perform security research only when ALL are true:
1. A real, active program explicitly authorizes testing.
2. The exact target is in scope.
3. Planned techniques are permitted.
4. The program rules and scope are captured before testing.
5. There is a recognized submission channel.
6. Testing is minimally invasive and stops when authorization becomes unclear.

Forbidden:
- random website testing
- out-of-scope testing
- persistence
- destructive actions
- unnecessary access to user data
- lateral movement beyond minimal proof
- extortion
- sale of vulnerabilities outside the authorized disclosure path
