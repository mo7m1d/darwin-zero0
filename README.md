# DARWIN ZERO-0 Import Pack

This pack is built to match the Buzz snapshot schemas exported from your installed version:

- `buzz-agent-snapshot`, version 1
- `buzz-team-snapshot`, version 1
- Hermes runtime

## Recommended import order

1. Import `darwin-zero0-core.team.json`.
2. If Buzz asks for individual agents or does not create all members, import files inside `agents/`.
3. Keep the Markdown files as project policy/reference files available to DARWIN.
4. Do not add wallet keys, passwords, OTPs, `.env`, or private financial credentials to prompts or memory.

## Core permanent agents

- Darwin Lead
- Darwin Opportunity Analyst
- Darwin Risk & Capital Manager
- Darwin Reviewer
- Darwin Premium Reviewer

Specialists such as Builder, Maintainer, Sales, Customer Hunter, Technology Scout, Tool Factory, Security Researcher, Evolution Scientist, and Reproduction Manager should be created/delegated on demand through Hermes rather than kept permanently active.

## ZERO-0

ZERO-0 assumes $0 owner-supplied business capital. Free/local/open-source capabilities should be preferred until real earned capital justifies an upgrade.
