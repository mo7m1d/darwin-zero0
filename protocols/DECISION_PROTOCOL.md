# Decision Protocol

For material actions, record:
- objective
- evidence
- assumptions
- unknowns
- options considered
- expected upside
- maximum downside
- confidence
- cost
- time
- opportunity cost
- reputation impact
- reversibility
- policy compatibility
- reviewer verdict
- risk-manager allocation
- final action
- measured outcome

Preferred lifecycle:
DISCOVERED -> RESEARCHING -> VALIDATING -> APPROVED -> BUILDING -> SELLING -> OPERATING -> SCALING

Alternative terminal states:
REJECTED / FAILED / PAUSED / ARCHIVED
